# 20 ideas: what to remove, add and manage next

Focus stays the same: offline, Excel in, locked PDF payslips out, delivered through Outlook.

## Remove or simplify

1. **Merge Export into Send for Outlook.** Drafts already embed the PDF, so the Export step can become optional ("Need the files too?").
2. **Drop the Letter paper size.** Saudi employers print A4; one fewer choice.
3. **Hide "Filled example".** "Try with sample data" already shows the whole flow.
4. **Fold the Messages section into the banner.** Show the top three issues inline; keep the full list one click away.
5. **Hide the Columns section when everything matched.** Show it only when something was guessed or ignored.

## Add

6. **Arabic interface toggle (RTL).** Same app, Arabic labels, right-to-left layout.
7. **Bilingual payslip design.** Arabic and English labels side by side on the PDF.
8. **AES-256 passwords.** Replace the built-in RC4 lock with strong encryption (pdf-lib + pdf-encrypt, MIT).
9. **WPS / Mudad salary file export.** Generate the bank wage file from the same Excel, so one sheet feeds both payroll and payslips.
10. **Month-over-month check.** Upload last month's file; flag employees whose net pay changed by more than a set percentage.
11. **Auto-calculations.** GOSI for Saudi staff from basic + housing, overtime pay from hours, absence deduction from days.
12. **Verification QR on each payslip.** A short hash code an inspector or bank can check against the delivery log.
13. **Email signature block.** HR name, title and phone appended to every Outlook draft.
14. **Install as an app (PWA).** "Install" button on the hosted page; opens from the desktop and works fully offline.
15. **Payroll summary report.** One PDF for management with totals by department, cost centre and nationality.
16. **Dark mode.** Same aurora, deep-night palette.

## Manage

17. **Multiple company profiles.** Switch between saved companies (for accountants who serve several clients).
18. **Run history.** Keep a local list of past months with totals and delivery logs, searchable.
19. **Accessibility pass.** Full keyboard flow, screen-reader labels for every control, high-contrast check.
20. **Brand kit in the settings file.** Let each company set its own four app colours and the mascot's accent so the tool feels like theirs.
