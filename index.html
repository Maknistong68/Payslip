How should the Excel file look?
  • One row per employee. Required: a name column and at least one salary column. Everything else is optional.
  • Column names are matched flexibly ("Basic", "HRA", "Iqama No.", "Net Payable"…). Anything unclear can be mapped on the next screen.
  • Extra pay items: name a column Earning: Site Allowance. Extra deductions: Deduction: Housing Loan.
  • Company details go in a Settings sheet (the template has one). If your file has none, you can type them on the next screen.
  • Your logo: insert the picture on the Settings sheet (Insert → Pictures). A second picture is used as stamp/signature.
  • Names and text can be in English or Arabic.
